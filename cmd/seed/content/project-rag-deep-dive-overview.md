## Overview

A production-grade conversational AI platform built to *teach* RAG, not
just use it.

- Hybrid retrieval: dense embeddings + BM25 + cross-encoder reranking.
- GraphRAG and multi-hop retrieval across Qdrant and Neo4j.
- Pipeline explainer UI that exposes every retrieval stage live.
- Interactive Learning Hub with hands-on RAG component demos.
